# AstroPlanner

AstroPlanner to mobilne narzędzie do planowania i prowadzenia projektów astrofotograficznych DSO.

Projekt powstał pierwotnie na mój własny użytek i jest obecnie rozwijany jako publiczna beta.

## Aktualna wersja

**v0.7.2 — Public Beta**

AstroPlanner umożliwia m.in.:

- planowanie sesji dla obiektów DSO,
- sprawdzanie wysokości obiektu, kulminacji i warunków związanych z Księżycem,
- korzystanie z katalogów Messier, NGC/IC, LDN, Abell i innych,
- dodawanie własnych obiektów,
- definiowanie teleskopów, kamer, filtrów i korektorów,
- tworzenie własnych profili sprzętowych,
- prowadzenie projektów i celów integracji,
- zapisywanie sesji LIGHT i klatek kalibracyjnych,
- prowadzenie dziennika sesji,
- eksport i import danych jako backup.

Aplikacja działa jako PWA i może zostać zainstalowana na ekranie głównym telefonu.
